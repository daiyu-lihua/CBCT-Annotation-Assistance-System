# 环境说明与快速上手

本文面向首次拿到本项目（clone 到本机）的成员，介绍怎么跑起来。

## 一、项目目录结构（重构后）

```
CBCT_Annotation_Assistance_System/
├── user/                    用户层
│   ├── plugin/              3D Slicer 插件本体（CBCTAnnotator.py + lib/ApiClient.py）
│   └── launcher/            启动入口（本目录）：一键启动、环境说明
├── implementation/          实现层：后台服务与模型接入
│   ├── server/inference/    本地推理服务端（现为 mock 假后端）
│   ├── model/               模型接入（预留，待接 A 组模型）
│   └── agent/               Agent 调度（预留）
├── docs/                    项目介绍 + 用户文档 + 接口方案
├── data/                    数据层：inputs 原始数据、outputs 运行产物（均不入库）
└── README.md
```

## 二、前置环境

- **Python 3.9+**，需装有依赖：
  ```bash
  pip install fastapi uvicorn nibabel numpy
  ```
  本项目在 Conda 的 `nninteractive` 环境运行（建议先 `conda activate nninteractive`）。
- **3D Slicer 5.x**：用于加载前端插件。

## 三、启动本地推理服务端

项目有两个服务端实现（地址相同，二选一运行）：

### 方式 A：ToothSeg 真实推理（推荐，已接入 A 组模型）

双击一键脚本：
```
user\launcher\一键启动ToothSeg服务.bat
```

命令行（在项目根目录）：
```powershell
E:\miniconda3\envs\nninteractive\python.exe implementation\server\inference\toothseg_server.py
```

启动成功会打印：`CBCT ToothSeg server -> http://127.0.0.1:8000/api/v1`

注意：`/predict` 完整双分支推理约 30-90 分钟（8GB 显卡，RTX 4060 Laptop 实测交接值），同步等待期间不要关闭窗口；同一时刻只允许一个推理任务。

### 方式 B：mock 假后端（前端联调用，秒回）

双击 `user\launcher\一键启动服务.bat`，或：
```powershell
python implementation\server\inference\mock_server.py
```

启动成功会打印：`CBCT mock server -> http://127.0.0.1:8000/api/v1`

## 四、加载 3D Slicer 插件

在 Slicer：Edit → Application Settings → Modules → Additional module paths 添加：
```
<你的项目路径>\CBCT_Annotation_Assistance_System\user\plugin
```
重启 Slicer，模块搜索 `CBCT` 打开。

## 五、各层数据流向

用户层(插件) → 本地服务端(HTTP) → (模型/Agent，预留) → data/outputs 落盘产物。
原始 CBCT 放 `data/inputs`，运行产物放 `data/outputs`，Statlab者不入库（见 .gitignore）。
